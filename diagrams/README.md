# Diagrams

This folder holds the **original design diagrams** from Reviews 1 to 3 (PNG and draw.io, kept
unchanged). The **current diagrams**, the ones that match the final code, are generated by
scripts and written to `report/figures/`. Use the generated ones in the report, the paper, the
slides and the README.

### Visual language

The same palette is used in every figure (`report/diagrams/_common.py`):

| Colour | Meaning |
|---|---|
| amber | answerability gates (Gate 1, Gate 2, optional Gate 3) and gate decisions |
| red | emergency fast-path / ESCALATE |
| blue | calls to the local LLM (Ollama) |
| grey | deterministic code (no LLM) |
| green | pre-vetted templates and privacy controls |
| purple | storage: PostgreSQL, Qdrant, files, key material and ciphertext |
| white, dark border | people and the UI |
| dashed border / arrow | optional or speculative path |

Fonts are Arial, which ships with both Windows and macOS. SVG text stays as text, so it can be
edited.

### Rebuild

From the repository root:

```bash
# macOS
.venv-mac/bin/python report/diagrams/build_all.py
# Windows (PowerShell)
.venv\Scripts\python report\diagrams\build_all.py
# a subset
python report/diagrams/build_all.py er_diagram fsm_soft_ask
```

Requirements: the project's own `matplotlib` (Pillow comes with it). For `er_diagram` you
also need Graphviz `dot` on `PATH` (`brew install graphviz`, `winget install graphviz` or
`choco install graphviz`; check with `dot -V`). The build needs no services, no Ollama and no
database.

Quality gates built into the scripts:

* **Text overflow.** Every hand-placed figure measures each text against its box with the
  real renderer. If anything overflows, the build fails (`_mpl.Canvas.check`).
* **ER drift.** The ER build fails if the table set changes, or if the encrypted-column
  markers in `medbridge/db/models.py` stop matching the figure.
* **Conditions drift.** The evaluation design fails if `AblationConfig.all_names()` gains a
  preset that has no label.
* **Reproducible.** Rebuilds are byte-identical. Files carry no timestamps, SVG ids are
  stable, and set-ordered data is sorted. This was verified with two builds under different
  `PYTHONHASHSEED` values.

### Using them in the report

* A4 portrait text width is about 5.8 in with a 1.5 in binding margin. At that width,
  `architecture_pipeline` and `evaluation_design` fill a portrait page. `sequence_turn`,
  `er_diagram`, `dataflow`, `deployment` and `privacy_flow` read best on a landscape page,
  or at full width when the SVG/PDF can be zoomed. `fsm_soft_ask` fits at full text width.
* Suggested placement: Chapter 3 (system design) for the architecture, sequence, FSM, ER,
  data-flow, deployment and privacy figures; Chapter 3 (experimental design) for
  `evaluation_design`.
* For the IEEE two-column paper, use `architecture_pipeline` as a full-width `figure*`.
